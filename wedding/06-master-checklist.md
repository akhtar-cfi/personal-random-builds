# Master Checklist

Phased by how far out we are, then a per-function day-of list. Tick as done. This is a
generic-but-practical India-wedding checklist — we'll prune/expand once the actual event
set, date, and scope are known. Move anything already done into `07-decisions-log.md`.

## Phase 1 — Foundation (do first)
- [ ] Confirm date(s) — check auspicious-date/muhurat constraints if relevant
- [ ] Confirm total budget + who contributes
- [ ] Confirm guest-count band + which events happen
- [ ] Decide: professional planner vs family-managed
- [ ] Privacy decision for data (§K) — where sensitive detail lives
- [ ] Assign point-persons per workstream (venue, food, guests, logistics, outfits)

## Phase 2 — Big bookings (lock early — these sell out)
- [ ] Venue(s) booked + advance paid
- [ ] Caterer booked (menu direction + rough per-plate)
- [ ] Photographer + videographer booked
- [ ] Decor vendor booked
- [ ] Start outfit ordering (long lead times — bride first)
- [ ] Book makeup/hair + mehendi artists
- [ ] Book music/DJ/entertainment

## Phase 3 — Guests & communications
- [ ] Finalise guest list (per event)
- [ ] Design invitations (digital + print?)
- [ ] Send invitations (verify right lead time for your community)
- [ ] Set up RSVP tracking
- [ ] Block guest accommodation
- [ ] Plan guest transport (+ safe late-night return — see road-safety note)

## Phase 4 — Details
- [ ] Menu tasting + finalise menu
- [ ] Return gifts / shagun / gifting plan
- [ ] Rituals/pooja/nikah items list (per community) + officiant confirmed
- [ ] Jewellery finalised & secured
- [ ] Beauty prep timeline (trials done)
- [ ] Marriage registration / legal paperwork (verify local process)
- [ ] Emergency kit + first-aid + point-of-contact list

## Phase 5 — Final 2 weeks
- [ ] Final headcount to caterer
- [ ] Confirm all vendors + payment schedule + arrival times
- [ ] Day-of run sheet (timeline per event, who does what)
- [ ] Assign day-of coordinators / family point-persons
- [ ] Confirm transport pickups + driver details
- [ ] Pack/checklist for bride (outfits, accessories, documents)

## Day-of essentials (per function)
- [ ] Run sheet printed + shared with point-persons
- [ ] Vendor arrival + setup times confirmed
- [ ] Emergency contacts + cash/UPI for on-day payments
- [ ] Guest hospitality (water, seating, elderly/kids care)
- [ ] Transport + parking + safe return sorted
- [ ] Someone owns the timeline (keeps things on schedule)

## Road-safety add-ons (optional, your domain)
- [ ] Vetted cab/driver tie-up for guest travel
- [ ] Designated-driver / "don't drink & drive" nudge if alcohol served
- [ ] Well-lit parking + clear signage
- [ ] Late-night safe-return plan for outstation & elderly guests
