# Sister's Wedding — Planning Workspace

Persistent home for planning my sister's wedding. Everything is saved here so nothing
is lost between sessions. Started 2026-09-12.

> ⚠️ **PRIVACY — READ FIRST.** This GitHub repo is **PUBLIC**. Anything committed here
> is visible to anyone on the internet. Do **not** put in these files:
> - Real full names of the couple/family (use first names or initials if unsure)
> - Guests' phone numbers, emails, or home addresses (third-party PII)
> - Exact budget figures you'd rather keep private, or signed contracts/quotes
>
> **Recommended:** keep the *framework* here (checklists, timeline, budget categories,
> vendor status) and keep *sensitive detail* (full guest list w/ contacts, exact money,
> contracts) in a **private Google Sheet / Drive** or a **private repo**. Decision pending
> from Akhtar — see `00-intake-questions.md` §K. Files below currently contain **no real
> personal data** — only templates.

## How this workspace is organised

| File | Purpose |
|---|---|
| `00-intake-questions.md` | Questionnaire — fill this in (or answer in chat) so planning can start |
| `01-overview.md` | Living one-page summary of confirmed facts (the source of truth) |
| `02-timeline-and-events.md` | Which functions/events, the dates, and the count-back timeline |
| `03-budget.md` | Budget tracker — total, category splits, estimate vs actual, payments |
| `04-guest-list.md` | Guest tracking by event (see privacy note — no contacts in public repo) |
| `05-vendors.md` | Vendor shortlist + booking/advance/balance status per category |
| `06-master-checklist.md` | Master task list, phased (T-minus) and by function |
| `07-decisions-log.md` | Running log of decisions made, so we never re-litigate them |
